# The Mandarin Erenköy

Site vitrine de **The Mandarin Erenköy**, café spécialisé en lattes, americanos et pâtisseries. La direction artistique associe l'énergie du Neo-Retro Diner à une composition Editorial Pop.

## Structure

```text
.
├── index.html
├── src
│   ├── assets
│   │   ├── icons
│   │   │   └── favicon.svg
│   │   └── images
│   ├── css
│   │   └── main.css
│   └── js
│       └── main.js
└── README.md
```

## Démarrage

Le projet n'a aucune dépendance ni étape de compilation. Ouvrez `index.html` dans un navigateur ou servez le dossier avec un serveur HTTP local.

Les couleurs, typographies, espacements et effets globaux sont centralisés sous forme de propriétés personnalisées dans `src/css/main.css`.
